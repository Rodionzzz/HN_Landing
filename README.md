# 🎃 Halloween Night Landing Page

Стильный и адаптивный лендинг для мероприятия **Halloween Night**, созданный для презентации ивента и демонстрации атмосферных фотографий с прошедших вечеринок.

## 🚀 Особенности проекта
- **Атмосферный дизайн:** тематическое оформление под стиль Halloween.
- **Интерактивная галерея:** удобный просмотр фотографий с мероприятия.
- **Адаптивность:** корректное отображение на любых устройствах (смартфоны, планшеты, ПК).

## 🛠 Технологии
- **Frontend:** React, Vite, HTML5, CSS3, JavaScript (ES Modules)
- **Управление ассетами:** модульная структура работы с путями и изображениями
